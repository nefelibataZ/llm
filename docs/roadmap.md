# 学习路线与验收

1. **工程基础（当前）**：理解包结构、命令行、依赖管理、检索与引用。验收：全新环境安装后离线示例和测试通过。
2. **真实 LLM 调用**：增加 provider 接口和环境变量配置，支持替换供应商。验收：模型能依据上下文回答，超时和失败有明确提示；离线测试不消费额度。
3. **RAG**：加入文档解析、分块、嵌入、向量存储和重排。验收：以带标注的问题集比较召回率、引用正确率、延迟和成本。
4. **EduAgent 编排**：逐个加入试卷批改、简历审查和模拟面试，再增加意图路由和状态管理。验收：每个任务有独立输入输出规范和失败测试；批改由教师确认。
5. **服务化**：根据需要加入 FastAPI、流式响应、会话持久化和前端。验收：会话隔离、权限控制、日志脱敏及端到端流程通过。

优先保持一个可运行的纵向闭环，每次只增加一个能力。Milvus、Redis、数据库和多智能体框架在实际需求出现后引入。
